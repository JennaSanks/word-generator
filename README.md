# Word Generator

A simple Flask-based web application that generates random words for learning, games, creative writing, and vocabulary practice. The application provides a clean user interface where users can generate random words with a single click.

---

## Features

- Generate random words instantly.
- Simple and responsive web interface.
- Built using Flask.
- Easy to customize with your own word list.
- Lightweight and beginner-friendly project.

---

## Technologies Used

- Python 3.x
- Flask
- HTML5
- CSS3
- JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/JennaSanks/word-generator.git
cd word-generator
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## Running the Application

Start the Flask server:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

---

## Usage

1. Launch the application.
2. Open it in your web browser.
3. Click the **Generate Word** button.
4. A random word will be displayed on the screen.

---

## Project Workflow

1. User opens the web application.
2. Flask serves the webpage.
3. User requests a new word.
4. The application randomly selects a word.
5. The generated word is displayed instantly.
